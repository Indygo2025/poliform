# ПОЛИФОРМ КОМПАНИ — сайт

Статический B2B-сайт производства пластмассовых плит, полос, труб и профилей.
Без CMS, без бэкенда, без формы заявки. Сборка — чистый HTML/CSS/JS, деплой через GitHub Pages.

## Структура

```
poliform/
├── index.html              главная
├── products.html           каталог 7 направлений
├── about.html              о компании
├── css/style.css           тема (пластик: глянец, скругления, рёбра)
├── js/main.js              меню, reveal, тикер, счётчики
├── images/                 SVG (пластиковые текстуры + схемы, без растра)
├── .github/workflows/      деплой на GitHub Pages
├── robots.txt
└── sitemap.xml
```

## Деплой

Push в `main` → workflow разворачивает сайт. Текущий адрес: `https://indygo2025.github.io/poliform/`
Для своего домена: Settings → Pages → Custom domain.

## Дизайн-материал

Визуальный язык — литьё под давлением и переработка пластмасс, а не бетон:

- скруглённые радиусы (`--r`) вместо острых углов — деталь отлитая, а не вырезанная;
- глянцевый верхний блик и мягкий отражённый свет снизу на каждой панели;
- полупрозрачные акриловые вставки для фото- и картозаглушек;
- мягкие тени с холодным подсветом вместо жёсткого смещения;
- сигнальный жёлтый сохранён как акцент — глянцевая отливка.

Поверхности гладкие: рифление и поперечные полосы убраны по требованию заказчика,
акцент сделан бликами и градиентами, а не текстурой.

`images/plastic.svg` — мелкое зерно поверхности.

## Что нужно заменить перед запуском

Контакты сейчас заглушки. Поиск по проекту: `sales@poliform.ru`, `+79000000000`, `t.me/poliform`, `indygo2025.github.io/poliform`.

| Что | Файлы |
|---|---|
| Телефон | все 3 HTML + `tel:` ссылки |
| E-mail | все 3 HTML + `mailto:` ссылки |
| Telegram | все 3 HTML |
| Домен | `sitemap.xml`, `robots.txt`, JSON-LD в `index.html` |
| Логотип | `images/favicon.svg` + инлайн-SVG знак в шапке и футере |

Заявления, которые нужно подтвердить у владельца перед запуском:

- опыт производства с 2004 года (в тексте помечен как предварительный);
- сценарии применения в блоке `.use-grid` на главной — роллетные ворота, заборы, кабель-каналы, крепёж, транспортная упаковка, баки. Они основаны на кодах ОКВЭД, а не на подтверждённом ассортименте. Если производство их не выпускает — блок удаляется целиком.

## Фотографии

Реальные фото цеха, склада и продукции от клиента пока нет. Заглушки:
`.photo-slot`, `.gallery-slot` в `index.html`, `products.html`, `about.html`.
Когда придут снимки — кладутся в `images/` и заменяют разметку заглушек.

SVG-схемы (`sheets.svg`, `pipes.svg`, `film.svg`, `profiles.svg`, `construction.svg`, `packaging.svg`, `bulk.svg`, `hero.svg`, `rolling.svg`, `fence.svg`, `duct.svg`, `fasteners.svg`, `stretch.svg`, `tank.svg`, `logistics.svg`) — рисованные иллюстрации, не фотографии. Схема упаковки условная: сам код ОКВЭД 22.22 подтверждает плёнку и полотна в рулонах, а не упаковку как товарную позицию. Раздел честно помечен «по запросу».

## Ограничения контента

Сайт намеренно не публикует марки полимеров, типоразмерный ряд, цены и наличие. Причина: эти данные в ЕГРЮЛ отсутствуют, а подтвердить их может только клиент. Вместо конкретных ТТХ — формулировки «по ТЗ» и ссылки на коды ОКВЭД. Так текст не врёт и не создаёт ожиданий, которые компания не закроет.

Если клиент пришлёт реальную номенклатуру, страницы `products.html` и блоки `.card-specs` в `index.html` заполняются конкретикой.
