# ПОЛИФОРМ КОМПАНИ — интернет-магазин пластиковых изделий

Статический сайт собственного производства: лотки и туалеты для кошек, миски одинарные и двойные.
Без CMS, без бэкенда и без серверной обработки форм. Корзина и режим цены живут в `localStorage`,
заявка собирается в текст и отправляется в Telegram или по телефону. Деплой — GitHub Pages.

## Опт и розница

- Розница: шаг `1 шт.`, цена за штуку.
- Опт: шаг равен `packCount` (20–600 шт.), минимальный заказ — один полный бокс. Цена в каталоге указана **за 1 шт.**, рядом всегда показана стоимость бокса.
- Режим хранится в `localStorage` (`poliform.mode`) и действует на всех страницах.
- В корзине оптовая и розничная части считаются отдельно, поэтому смешанный заказ прозрачен по сумме.
- Количество нормализуется функцией `normQty()` — ввод вручную не ломает кратность боксу.

## Фотографии и описания

Снимки и тексты взяты с Сима-Лэнда по артикулам (`fetch_sima.ps1`), оптимизированы
`optimize_images.ps1` (.NET `System.Drawing`, без Python и ImageMagick). Перед публикацией
проверить rights на использование фото и подтвердить описания у владельца производства.

Каждая ссылка на источник хранится в `data/products.json` в поле `sima`.

## Что заменить перед запуском

Контакты сейчас заглушки. Поиск по проекту: `sales@poliform.ru`, `+79000000000`, `t.me/poliform`.

| Что | Где |
|---|---|
| Телефон | 4 HTML + `tel:` ссылки |
| E-mail | 4 HTML + `mailto:` ссылки |
| Telegram | 4 HTML + `js/shop.js` (ссылка `share/url`) |
| Домен | `sitemap.xml`, `robots.txt`, JSON-LD в HTML |
| Логотип | `images/favicon.svg` + инлайн-SVG в шапке и футере |
| Фото цеха и склада | заглушки `.photo-slot` в `about.html` |

Подтвердить у владельца: актуальные цены, наличие по цветам, вес брутто, габариты двойных мисок,
даты регистрации компании. Эти значения лежат в `data/products.json` и дублируются текстом
в `about.html` и `index.html` — правьте в обоих местах.

## Деплой

Push в `main` → workflow разворачивает сайт на GitHub Pages.
Адрес по умолчанию: `https://indygo2025.github.io/poliform/`. Свой домен: Settings → Pages → Custom domain.

## Локальный запуск

Каталог грузится через `fetch()`, поэтому нужен HTTP, а не открытие файла:

```powershell
python -m http.server 8899 --directory poliform-plastic
```

## Проверка

```powershell
node --check poliform-plastic/js/shop.js
```

JSON валиден, все 94 изображения из `data/products.json` существуют, классы разметки
и JS покрыты правилами в CSS.
