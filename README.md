# ПОЛИФОРМ КОМПАНИ — интернет-магазин пластиковых изделий

Статический сайт собственного производства: лотки и туалеты для кошек, миски одинарные и двойные.
Без CMS, без бэкенда и без серверной обработки форм. Корзина и режим цены живут в `localStorage`,
заявка собирается в текст и отправляется в Telegram или по телефону. Деплой — GitHub Pages.

## Ассортимент

81 артикул, 4 категории (прямоугольные лотки и туалеты, округлые лотки, миски одинарные, миски двойные).
Главная показывает 8 популярных артикулов в автоленте.

## Опт и розница

- Розница: шаг `1 шт.`, цена за штуку.
- Опт: шаг равен `packCount` (20–600 шт.), минимальный заказ — один полный бокс. Цена в каталоге указана **за 1 шт.**, рядом всегда показана стоимость бокса.
- Режим хранится в `localStorage` (`poliform.mode`) и действует на всех страницах.
- В корзине оптовая и розничная части считаются отдельно, поэтому смешанный заказ прозрачен по сумме.
- Количество нормализуется функцией `normQty()` — ввод вручную не ломает кратность боксу.

## Цвета и блок «Цвет»

Один и тот же товар в разных расцветках — отдельные карточки (свой артикул, цена, фото, наличие),
но на витрине связаны как на маркетплейсе: на карточке под названием — блок «Цвет» с фотографиями
расцветок, на плитке каталога — те же миниатюры. Клик открывает карточку этой же позиции в другом цвете.

Связь задаётся полем `colorGroup`. Как связать в админке (**Каталог → товар → блок «Связка расцветок»**):
«Связать с другим товаром», ручной ввод группы, «Сделать такую же в другом цвете».

## SEO

- `<link rel="canonical">`, `og:url`, `og:image`, `og:site_name`, `og:locale`, `og:title`, `og:description`, `og:type` — в `inc/layout.php` (`pl_head`).
- `twitter:card`, `twitter:title`, `twitter:image` — для карточек соцсетей.
- `<meta name="robots">` — `index, follow` для витрины, `noindex, nofollow` для `cart.php`.
- `robots.txt` — allow `/`, disallow админки/API/инструментов; ссылка на `sitemap.xml`.
- `sitemap.xml` — главная, каталог, about + 81 страница товара (`product-<sku>.html`).
- JSON-LD: `BreadcrumbList` (шаги) + `Product` (цены, остаток) — генерируются PHP на карточке товара.

## Безопасность

- Заголовки: CSP (без внешних скриптов/стилей, шрифты Google разрешены), `X-Content-Type-Options: nosniff`,
  `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`.
- Закрыт веб-корень: `site.db`, бэкапы, админка/API/инструменты/исходники недоступны публично.
- CSRF для скачиваний (`api.php?action=backup&csrf=`), rate limit, серверный пересчёт цен,
  маскировка настроек в ответах API, валидация сессии.

Контакты сейчас заглушки. Поиск по проекту: `sales@poliform.ru`, `+79000000000`, `t.me/poliform`.

| Что | Где |
|---|---|
| Телефон | 4 HTML + `tel:` ссылки |
| E-mail | 4 HTML + `mailto:` ссылки |
| Telegram | 4 HTML + `js/shop.js` (ссылка `share/url`) |
| Домен | `sitemap.xml`, `robots.txt`, JSON-LD в HTML |
| Логотип | `images/favicon.svg` + инлайн-SVG в шапке и футере |
| Фото цеха и склада | заглушки `.photo-slot` в `about.html` |

Подтвердить у владельца: актуальные цены, наличие по цветам, вес брутто, габариты двойных мисок,
даты регистрации компании. Эти значения лежат в `data/products.json` и дублируются текстом
в `about.html` и `index.html` — правьте в обоих местах.

## Деплой

Push в `main` → workflow разворачивает сайт на GitHub Pages.
Адрес по умолчанию: `https://indygo2025.github.io/poliform/`. Свой домен: Settings → Pages → Custom domain.

## Локальный запуск

Сайт на PHP и SQLite, поэтому нужен Apache с PHP (в XAMPP уже включён) — из корня `htdocs`:

```
http://localhost/poliform-plastic/
```

Открывать файлы напрямую (`file://`) или раздавать через `python -m http.server` нельзя:
страницы собираются PHP, а данные лежат в `site.db`. MySQL не нужен.

## Проверка

```powershell
php -l <file>.php
node --check poliform-plastic/js/shop.js
php tools/build-static.php
```
JSON валиден, все изображения из `data/products.json` существуют, классы разметки и JS покрыты правилами в CSS.
